# Developer Dashboard Lab

## Project Overview
A lightweight web application displaying developer resources, built to demonstrate modern front-end tooling and build automation.

## Tech Stack
* **Bundler:** Vite
* **Linter:** ESLint
* **Formatter:** Prettier
* **Language:** JavaScript (Vanilla)

## Key Scripts
- `npm run dev`: Starts the local development server.
- `npm run build`: Bundles and minifies the app for production.
- `npm run preview`: Previews the production build locally.

## Reflection
Reflecting on the process, Vite improved my Developer Experience  with Hot Module Replacement I saw my changes instantly without refreshing. For the user, the build process ensures they only download the code they need, making the dashboard load significantly fastelong bundling wait times found in older tools.
